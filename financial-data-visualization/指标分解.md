# 财务指标分解

## 合并资产负债表指标

#### 1. 应收账款占总资产比率 及同比增速
- **公式**: 应收账款 / 总资产
- **来源**:
  - 应收账款 [资产负债表, `"应收账款"`]
  - 总资产 [资产负债表, `"资产总计"`]

#### 2. 应收账款占营收比率
 及同比增速
- **公式**: 应收账款 / 营业收入
- **来源**:
  - 应收账款 [资产负债表, `"应收账款"`]
  - 营业收入 [利润表, `"营业收入"`]

#### 3. 应收账款周转率 及同比增速
- **公式**: 营业收入 / 应收账款
- **来源**:
  - 营业收入 [利润表, `"营业收入"`]
  - 应收账款 [资产负债表, `"应收账款"`]

#### 4. 预付账款 及同比增速
- **公式**: 预付款项
- **来源**:
  - 预付款项 [资产负债表, `"预付款项"`]

#### 5. 存货 及同比增速
- **公式**: 存货
- **来源**:
  - 存货 [资产负债表, `"存货"`]

#### 6. 存货周转率 及同比增速
- **公式**: 营业成本 ÷ 平均存货
  - 平均存货 = （期初存货 + 期末存货） ÷ 2
- **来源**:
  - 营业成本 [利润表, `"营业成本"`]
  - 期末存货 [资产负债表, `"存货"`]

#### 7. 固定资产 及同比增速
- **公式**: 固定资产
- **来源**:
  - 固定资产 [资产负债表, `"固定资产及清理合计"`]

#### 8. 固定资产周转率 及同比增速
- **公式**: 营业收入 ÷ 平均固定资产
  - 平均固定资产 = （期初固定资产 + 期末固定资产） ÷ 2
- **来源**:
  - 营业收入 [利润表, `"营业收入"`]
  - 期末固定资产 [资产负债表, `"固定资产及清理合计"`]

#### 9. 无形资产和开发支出 及同比增速
- **公式**: 无形资产 + 开发支出
- **来源**:
  - 无形资产 [资产负债表, `"无形资产"`]
  - 开发支出 [资产负债表, `"开发支出"`]

#### 10. 商誉 及同比增速
- **公式**: 商誉
- **来源**:
  - 商誉 [资产负债表, `"商誉"`]

#### 11. 商誉占总资产比例 及同比增速
- **公式**: 商誉 / 总资产
- **来源**:
  - 商誉 [资产负债表, `"商誉"`]
  - 总资产 [资产负债表, `"资产总计"`]

#### 12. 有息负债 及同比增速
- **公式**: 短期借款 + 应付短期债券 + 一年内到期的非流动负债 + 长期借款 + 应付债券 + 租赁负债
- **来源**:
  - 短期借款、一年内到期的非流动负债、租赁负债等 [资产负债表, 相关字段]

#### 13. 现金债务比 及同比增速
现金覆盖比
- **公式**: 现金及现金等价物 / 有息负债
- **来源**:
  - 现金及现金等价物 [现金流量表, `"期末现金及现金等价物余额"`]
  - 有息负债 [资产负债表, 见第12项来源]

#### 14. 扩展现金债务比 及同比增速
流动资产覆盖比
- **公式**: (现金及现金等价物 + 交易性金融资产 + 一年内到期的非流动资产 + 其他流动资产) ÷ 有息负债
- **来源**:
  - 现金及现金等价物 [现金流量表, `"期末现金及现金等价物余额"`]
  - 交易性金融资产、一年内到期的非流动资产、其他流动资产 [资产负债表, 相关字段]
  - 有息负债 [资产负债表, 见第12项来源]


## 合并利润表指标

#### 1. 营业总收入 及同比增速
- **公式**: 营业总收入
- **来源**:
  - 营业总收入 [利润表, `"营业总收入"`]

#### 2. 营业总成本 及同比增速
- **公式**: 营业总成本
- **来源**:
  - 营业总成本 [利润表, `"营业总成本"`]

#### 3. 毛利润 及同比增速
- **公式**: 营业总收入 - 营业成本
- **来源**:
  - 营业总收入 [利润表, `"营业总收入"`]
  - 营业成本 [利润表, `"营业成本"`]

#### 4. 毛利率 及同比增速
- **公式**: 毛利润 / 营业总收入
  - 毛利润 = 营业总收入 - 营业成本
- **来源**:
  - 毛利润 [计算得出]
  - 营业总收入 [利润表, `"营业总收入"`]

#### 5. 销售费用 及同比增速
- **公式**: 销售费用
- **来源**:
  - 销售费用 [利润表, `"销售费用"`]

#### 6. 管理费用 及同比增速
- **公式**: 管理费用
- **来源**:
  - 管理费用 [利润表, `"管理费用"`]

#### 7. 研发费用 及同比增速
- **公式**: 研发费用
- **来源**:
  - 研发费用 [利润表, `"研发费用"`]

#### 8. 财务费用 及同比增速
- **公式**: 财务费用
- **来源**:
  - 财务费用 [利润表, `"财务费用"`]

#### 9. 费用率 及同比增速
- **公式**: (销售费用 + 管理费用 + 研发费用) / 营业总收入
- **来源**:
  - 销售费用 [利润表, `"销售费用"`]
  - 管理费用 [利润表, `"管理费用"`]
  - 研发费用 [利润表, `"研发费用"`]
  - 营业总收入 [利润表, `"营业总收入"`]

#### 10. 费用占毛利润 及同比增速
- **公式**: (销售费用 + 管理费用 + 研发费用) / 毛利润
  - 毛利润 = 营业总收入 - 营业成本
- **来源**:
  - 销售费用 [利润表, `"销售费用"`]
  - 管理费用 [利润表, `"管理费用"`]
  - 研发费用 [利润表, `"研发费用"`]
  - 毛利润 [计算得出]

#### 11. 营业利润 及同比增速
- **公式**: 营业利润
- **来源**:
  - 营业利润 [利润表, `"营业利润"`]

#### 12. 营业利润率 及同比增速
- **公式**: (营业总收入 - 营业成本 - 销售费用 - 管理费用 - 研发费用) / 营业总收入
- **来源**:
  - 营业总收入 [利润表, `"营业总收入"`]
  - 营业成本 [利润表, `"营业成本"`]
  - 销售费用 [利润表, `"销售费用"`]
  - 管理费用 [利润表, `"管理费用"`]
  - 研发费用 [利润表, `"研发费用"`]

#### 13. 营业外收入占比 及同比增速
- **公式**: 营业外收入 / 营业总收入
- **来源**:
  - 营业外收入 [利润表, `"营业外收入"`]
  - 营业总收入 [利润表, `"营业总收入"`]

#### 14. 净利润 及同比增速
- **公式**: 净利润
- **来源**:
  - 净利润 [利润表, `"净利润"`]

#### 15. 净利率 及同比增速
- **公式**: 净利润 / 营业总收入
- **来源**:
  - 净利润 [利润表, `"净利润"`]
  - 营业总收入 [利润表, `"营业总收入"`]

## 综合指标

#### 21. ROE
- **公式**: 净利率 × 总资产周转率 × 权益乘数
  - (净利润 / 营业收入) × (营业收入 / 总资产) × (总资产 / 所有者权益)

- **来源**:
  - 净利润 [利润表, `"净利润"`]
  - 营业收入 [利润表, `"营业收入"`]
  - 总资产 [资产负债表, `"资产总计"`]
  - 所有者权益（或股东权益） [资产负债表, `"所有者权益(或股东权益)合计"`，计算平均值]

#### 22. ROE净利率 及同比
- **公式**: 净利润 / 平均净资产
  - 平均净资产 = （期初净资产 + 期末净资产） ÷ 2
- **来源**:
  - 净利润 [利润表, `"净利润"`]
  - 平均净资产 [资产负债表, `"所有者权益(或股东权益)合计"`]

#### 23. 总资产周转率 及同比
- **公式**: 营业总收入 / 总资产
- **来源**:
  - 营业总收入 [利润表, `"营业总收入"`]
  - 总资产 [资产负债表, `"资产总计"`]

#### 24. 杠杆系数 及同比
- **公式**: 总资产 / 所有者权益
- **来源**:
  - 总资产 [资产负债表, `"资产总计"`]
  - 所有者权益 [资产负债表, `"所有者权益(或股东权益)合计"`]

#### 25. 总资产收益率 及同比
- **公式**: 净利润 / 总资产
- **来源**:
  - 净利润 [利润表, `"净利润"`]
  - 总资产 [资产负债表, `"资产总计"`]

#### 26. 生产资产回报率 及同比
- **公式**: (利润总额 + 所得税费用) ÷ 生产资产
  - 生产资产 = 固定资产及清理合计固定资产 + 在建工程合计 + 工程物资 + 生产性生物资产 + 无形资产 + 开发支出
- **来源**:
  - 利润总额 [利润表, `"利润总额"`]
  - 所得税费用 [利润表, `"所得税费用"`]
  - 固定资产及清理合计固定资产 [资产负债表, `"固定资产及清理合计"`]
  - 在建工程合计 [资产负债表, `"在建工程合计"`]
  - 工程物资 [资产负债表, `"工程物资"`]
  - 生产性生物资产 [资产负债表, `"生产性生物资产"`]
  - 无形资产 [资产负债表, `"无形资产"`]
  - 开发支出 [资产负债表, `"开发支出"`]
